# ACLA - Africa Climate Leadership Academy Demo

## Overview
This is a complete demo of the Africa Climate Leadership Academy website featuring two integrated platforms:

1. **Institutional Website** - Main organizational presence
2. **Youth Learning Platform** - E-learning management system

## How to Use

### Option 1: Open Directly in Browser
1. Extract the zip file
2. Open `index.html` in your web browser
3. All features will work immediately

### Option 2: Upload to Google Drive
1. Extract the zip file
2. Upload the entire folder to Google Drive
3. Share the `index.html` link with clients
4. They can view all features directly

## Features

### Institutional Website (Main Page)
- Professional homepage with hero section
- About ACLA section with mission and values
- 6 featured training programs
- Team leadership profiles
- Upcoming events calendar
- Contact form
- Responsive mobile design

### Learning Platform (/learn)
- Course discovery and search
- Advanced filtering system (category, level)
- 6 featured courses with details
- Course curriculum pages
- Student dashboard with progress tracking
- Course detail pages with learning outcomes
- Responsive design

## Navigation

- **Home Page**: `index.html` (or just open the folder)
- **Learning Platform**: Click "Learn" in the navigation menu
- **Courses**: Browse available courses
- **Dashboard**: View student progress
- **Contact**: Fill out contact form

## Technical Details

- **Framework**: React 19
- **Styling**: Tailwind CSS 4
- **Routing**: Client-side routing (Wouter)
- **UI Components**: shadcn/ui
- **Build**: Vite
- **Responsive**: Mobile-first design
